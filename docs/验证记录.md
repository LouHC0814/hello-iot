# 第一版验证记录

验证日期：2026-10-13。以下为本机实际执行结果。

## 环境

- Windows，Python 3.13.5，matplotlib 3.11.1。
- 使用指定的 Python 解释器绝对路径，配置与测试临时文件放在项目目录。
- PowerShell 启动脚本另外通过 Windows PowerShell 5.1 实际调用验证。

## 结果

| 检查 | 实际结果 |
| --- | --- |
| 自动化测试 | `unittest` 的 9 项测试全部通过 |
| 固定参数批量演示 | 120 条记录，开始 09:00:00+08:00，结束 09:59:30+08:00 |
| 文件一致性 | CSV 条数、来源、起止时间、温度均值与 JSON 摘要一致 |
| 示例统计 | 温度均值 26.42 °C，湿度均值 56.23 %RH |
| PNG 视觉检查 | 已打开图片，确认曲线、中文标签与时间信息正常 |
| 真实 TkAgg 回放 | 6 条模拟记录全部完成，生成 CSV、PNG、JSON |
| 真实窗口提前关闭 | 计划 10 条，在第 3 帧关闭，保留 3 条；`complete=false` |
| 启动脚本 | 单样本运行成功；Windows PowerShell 5.1 下双样本运行成功 |
| 非法命令行参数 | 0 个样本、NaN 间隔、无限回放间隔、非法时间均返回参数错误 |

TkAgg 检查确实使用了桌面图形后端和事件循环，验证时隐藏了窗口；模拟的是传感器数据。

GitHub Actions 的 Linux / Python 3.11、3.13 结果请以 PR 中的检查状态为准。本记录不代表真实 ESP32、DHT11 或串口已经验证。
